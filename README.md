## About

I'm a full stack software developer with a focus on building complete, production-ready web applications — from database schema to deployed UI. My work spans REST API architecture, frontend component systems, authentication infrastructure, and cloud deployment pipelines.

Engineering, to me, is a discipline of tradeoffs. Every system has constraints — I focus on identifying the right abstractions, writing maintainable code, and shipping software that holds up under real-world usage.

I care about reliability, clean interfaces between layers, and building things that don't require constant firefighting once deployed.

---

## What I Build

```
  Full Stack Applications     →   End-to-end ownership from data model to user interface
  REST API Systems            →   Resource modeling, versioning, auth, and documentation
  Frontend Architecture       →   Component design, state management, performance tuning
  Database Design             →   Schema modeling, indexing, query optimization
  Auth & Access Control       →   JWT, OAuth 2.0, refresh rotation, RBAC, session handling
  Production Deployments      →   CI/CD pipelines, containerization, cloud infrastructure
```

## Current Focus

- Deepening system design knowledge — distributed systems, event-driven architecture

- Frontend performance engineering: SSR/SSG tradeoffs, bundle optimization, Core Web Vitals
- Container orchestration and cloud-native deployment workflows
- Building in public and contributing to the Node.js / React open source ecosystem
